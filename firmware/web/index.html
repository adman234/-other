Joints

Hold a jog button to move; release to stop. Type a value and press Enter to move there.

System check

Hardware the controller can see, plus the automatic self-test. The self-test pulses each motor forward then back and checks its encoder and current.

Home switches

Press each switch by hand, or jog each joint across it. Each lamp lights while pressed; the checklist ticks once it has been seen pressed and released.

Motors, direction and current

Test runs one motor open-loop: +duty for a moment, then -duty. Pass = encoder counts up then down. "Disagree" means the motor and encoder are wired opposite: press Flip. Use Invert on the Calibrate tab to choose which way is positive.

Encoders

Disable the drivers, then turn each motor or joint by hand. Counts should change smoothly both ways; the range shows how far each one has moved since the last reset. Wrist motors A and B both move for pitch and roll.

  1. Home

    Each joint seeks its switch, creeps across it and zeroes on the far edge, always approached the same way. The gripper closes until it stalls. Order: shoulder, elbow, pitch, roll, gripper, base (base last; it swings).

  2. Measure travel

    Drives each joint slowly into both hard stops at reduced power, then returns home. The measured span against the manual's range gives counts per degree, the home angle and soft limits. Watch the arm and keep a hand near STOP. Wrist roll has no stops: use step 3.

    JointResultCounts min / maxMeasured /unitCurrent /unitHome atSoft limitsNote

  3. Wrist roll: one-turn method

    Put a mark on the gripper, press Start, jog roll exactly one full turn back to the mark, then press Done.
